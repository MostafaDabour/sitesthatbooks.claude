# SitesThatBook site repo

Static site for sitesthatbook.com, generated by Python from `src/`. Output lives in `site/`, which hosting serves directly.

Workflow for any change:
1. Edit files in `src/` (never hand-edit `site/`).
2. Run `./build.sh`.
3. Check: no em dashes or en dashes anywhere, all internal links resolve.
4. Commit both `src/` and `site/`, push to `main`. Hosting auto-deploys.
